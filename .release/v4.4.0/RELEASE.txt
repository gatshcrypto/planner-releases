Добавлены двусторонняя синхронизация Windows с мобильным планером и настройка iPhone из приложения: Настройки → Синхронизация → Настроить приложение для iPhone.

Настройка размещает мобильный планер и базу в собственном аккаунте Cloudflare, создаёт резервную копию Windows и переносит существующие записи. Доступ независим от ChatGPT. Мобильная версия добавляется на экран «Домой» через Safari. Изменения разных записей объединяются, конфликт одной записи требует выбора. Финансовые суммы сохраняются в копейках.

Проверены 178 сценариев Windows-интерфейса, 20 мобильных сценариев, 28 проверок правил и сервера, двусторонний обмен настоящего WPF-приложения с SQLite и мобильным браузером. Локальный OAuth callback, PKCE, обновление защищённого сеанса и последовательность публикации проверены с имитацией Cloudflare API.

Реальное развёртывание Cloudflare, пользовательский DPAPI и физический iPhone пока не проверены: рабочая среда блокирует соединение Cloudflare, поэтому настройку выполняет приложение на компьютере владельца. Уведомления iPhone являются обычными системными уведомлениями, не непрерывным будильником.
