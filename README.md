# Планер

Личный планер для Windows 11 и iPhone. Windows хранит данные локально; мобильная версия и синхронизация работают на собственном Cloudflare владельца.

[Последний выпуск](https://github.com/gatshcrypto/planner-releases/releases/latest) — установщик и полный архив исходников Windows и телефона.

Если приложение уже установлено, используйте кнопку «Обновить» внутри планера.

## Контроль и восстановление

Работа приложения не зависит от аккаунта ChatGPT. Для смены устройств нужны свой адрес сервера и ключ доступа. Сохраняйте ключ отдельно в личном менеджере паролей; не загружайте его в этот репозиторий.

В Windows: Настройки → Резервные копии. Выберите папку своего облачного диска или внешний накопитель. Автокопии создаются при запуске и каждые 15 минут, пока планер открыт. Копия только на системном диске не защищает от его поломки.

Сохраните вне GitHub/Cloudflare установщик, архив исходников, резервные копии данных и резервные коды своих аккаунтов. В архиве исходников есть инструкция сборки, а в архиве данных — инструкция восстановления. Это позволяет поддерживать и переносить приложение без этого чата.

Мобильное обновление отправляется на собственный сервер из Windows: Настройки → Синхронизация → Планер на iPhone → Обновить мобильную версию.
